# 🚀 AI-Powered Workplace Productivity Assistant

## 📌 Overview
The **AI-Powered Workplace Productivity Assistant** is a modern web-based application designed to help users automate everyday professional tasks using Artificial Intelligence.

This solution improves workplace efficiency by reducing the time spent on repetitive activities such as writing emails, summarizing meeting notes, organizing schedules, and managing tasks. It demonstrates how AI can be integrated into real-world business environments to enhance productivity, communication, and decision-making.

---

## 🎯 Objectives
- Automate repetitive workplace tasks  
- Improve productivity using AI-powered solutions  
- Apply prompt engineering techniques  
- Build a clean, responsive, and user-friendly interface  
- Promote ethical and responsible AI usage  
- Demonstrate practical AI implementation in business environments

## ✨ Features

### ✉️ Smart Email Generator
- Generates professional emails based on user input  
- Supports multiple tones:
  - Formal
  - Informal
  - Persuasive
  - Friendly
- Adapts messaging for different audiences:
  - Managers
  - Clients
  - Team members
- Saves time on repetitive communication tasks  

---

### 📝 Meeting Notes Summarizer
- Converts lengthy notes into concise summaries  
- Extracts:
  - Key discussion points
  - Decisions made
  - Action items
- Highlights important deadlines and responsibilities  
- Improves clarity and meeting follow-up efficiency  

---

### 📅 Task Planner / Scheduler
- Creates structured daily or weekly schedules  
- Prioritizes tasks based on:
  - Urgency
  - Importance
  - Deadlines
- Suggests better time management strategies  
- Helps users stay organized and productive  

---

### 🤖 AI Chat Interface
- Interactive AI assistant for workplace-related queries  
- Supports multiple prompts and intelligent responses  
- Simulates a real productivity assistant experience  
- Provides instant support for common professional tasks

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Nokulunga99/Nokulunga-aipoweredassistance.git
cd Nokulunga-aipoweredassistance
```

---

### 2️⃣ Install Dependencies

Using Bun:

```bash
bun install
```

---

### 3️⃣ Start the Development Server

```bash
bun run dev
```

---

### 4️⃣ Open the Application

Open your browser and visit:

```bash
http://localhost:5173
```
